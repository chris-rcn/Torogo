Feature definitions:

1. Contiguous to the previous move. Active if the candidate move is among the
8 neighboring points of the previous move. Also active for all features 2–7.
2. Save the string in new atari by capturing. The candidate move that is able
to save the string in new atari by capturing has this feature.
3. Same as Feature 2, which is also self-atari. If the candidate move has Feature 2
but is also a self-atari, then instead it has Feature 3 (Fig. 1).
4. Save the string in new atari by extension. The candidate move that is able
to save the string in new atari by extension has this feature.
5. Same as Feature 4, which is also self-atari.
6. Solve a new ko by capturing. If there is a new ko, then the candidate move
that is able to solve the ko by capturing any one of the neighboring strings
has this feature.
7. 2-point semeai. If the previous move reduces the liberties of a string to only
two, then the candidate move that is able to kill its neighboring string by
giving atari has this feature. Fig. 1 gives an example. This feature deals with
the most basic type of semeai.

MCTS - A good base to build upon.
RAVE - Guides the tree portion of MCTS in early visits.  Highly effective.
NPAT - Pattern policy (with ladder tactics) trained by REINFORCE.  Initializes RAVE stats on node creation.
PPAT - Playout patterns. Guides the playout portion of MCTS. Trained by simulation balancing.
       Promising; still WIP.

Maybe:
Use TD valuation as a tree prior.
Use TD valuation as a replacement for the tail of a playout (low variance).
No fit:
TD search - Very cool, but doesn't seem to have a place.
